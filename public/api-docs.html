Govsense AI — REST API Documentation

Base URL: /api · All responses in JSON · No authentication required

Protocol
HTTP/HTTPS
Response Format
application/json
Rate Limiting
None (public API)
1

Overview & Dashboard

GET /api/overview

Returns aggregate KPI metrics for the dashboard: total members, works, expenditure, fund utilization, and completion rates.

Query Params: scope — BOTH | MP | MLA (default: BOTH)
Response: { total_members, total_works, completed_works, ongoing_works, fund_utilization_pct, completion_rate_pct, ... }
GET /api/trends

Returns classification distribution trends and historical performance data.

Query Params: member_type — MP | MLA (optional)
GET /api/categories

Returns work category breakdown with counts and expenditure. Supports filtering by state.

Query Params: state_id — integer (optional)
GET /api/fy

Returns financial year-wise metrics for expenditure and allocation trends.

2

Members (MPs & MLAs)

GET /api/members/scatter

Returns member data for scatter plot visualization (fund utilization vs completion rate).

Query Params: member_type — MP | MLA | BOTH (default: MP)
GET /api/members/list

Paginated list of all members with filtering and sorting support.

Query Params: page (int), page_size (int, default 20), member_type, state, classification, sort
Response: { members: [...], total, page, page_size, total_pages }
GET /api/members/search

Search members by name. Used for autocomplete and header search.

Query Params: q (string, min 2 chars), limit (int, default 10)
GET /api/members/detail/{member_id}

Full member profile with performance scores, classification, risk level, and AI analysis.

Path Param: member_id — integer (required)
Response: { member: {...}, analysis: {...}, evidence: {...}, benchmarks: {...} }
GET /api/members/detail/{member_id}/works

Paginated works list for a specific member with status and cost filtering.

Query Params: page, page_size, status, sort
GET /api/peer-benchmark

Returns cluster average and national average benchmarks for a specific entity.

Query Params: member_id (int), state_id (int), member_type (MP | MLA)
3

States & UTs

GET /api/state-performance
Returns all states with performance scores, classification, and aggregate metrics.
GET /api/states
Lightweight state list for dropdowns and navigation.
GET /api/states/detail/{state_id}
Full state profile with performance, risk, AI analysis, member counts, and benchmarks.
GET /api/states/detail/{state_id}/works
Paginated works list for a specific state with filtering.
GET /api/states/detail/{state_id}/constituencies
Constituency-level breakdown within a state.
GET /api/constituencies
List constituencies, optionally filtered by state.
4

Works & Projects

GET /api/works

Paginated work records with extensive filtering, sorting, and search.

Query Params: page, page_size, state_id, member_id, category, status (completed | ongoing | pipeline | pending), q (search), sort
GET /api/projects/summary

Aggregated project analytics: KPIs, category breakdown, milestones, duration distribution, age cohorts, and cost slabs.

Query Params: state_id (int, optional)
GET /api/works/risk
Returns works flagged with cost, duration, or overdue anomalies with risk scores.
5

Risk & Intelligence

GET /api/risk/overview
Aggregate risk metrics: total entities, flagged works, anomaly counts, risk level distribution.
GET /api/risk/entities

Paginated risk entity list with filtering by risk level, entity type, and sorting.

Query Params: page, page_size, risk_level (CRITICAL | HIGH | MODERATE | LOW), entity_type (mp | mla | state), sort (score | flagged)
GET /api/risk/alerts
Recent risk alerts and anomaly detections. Returns top flagged entities across all types.
GET /api/intelligence/members
AI-generated intelligence summaries for members. Supports pagination and member_type filtering.
GET /api/intelligence/states
AI-generated intelligence summaries for states.
GET /api/intelligence/models
Model metadata: versions, training dates, and accuracy metrics for the ML scoring pipeline.
6

Classification & Evidence

GET /api/classification/distribution
Classification distribution across all members (count per category).
GET /api/classification/member/{member_id}
Detailed classification data for a specific member with score breakdown.
GET /api/classification/states
Classification data for all states with cluster assignments.
GET /api/classification/member/{member_id}/evidence
Supporting evidence data for a member's classification and risk assessment.
GET /api/classification/member/{member_id}/analysis
AI-generated analysis narrative for a specific member.
7

Utility & System

GET /api/data-updated
Returns the last data update timestamp and pipeline status.
